# x64ui 1.0.0-d

Major x64dbg UI/UX overhaul.

- Added the full x64dbg menu order and compact debugger toolbar.
- Added a resizable four-pane CPU workspace with disassembly, registers, dump, stack, info, branch markers, and breakpoints.
- Added graph, table, log, notes, source, script, and standard debugger views.
- Unified menus, toolbar controls, and debugger keyboard shortcuts through action handlers.
- Rebuilt the example around a realistic debugger session.
- Replaced the runtime source patcher with a validated request-first loader.
- Removed every dependency on the obsolete chunk path.
